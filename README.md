## Working with the notebooks

For each assignment section, we aim to use the following structure:

1. State the question or task.
2. Use a code cell to calculate or visualise the requested result.
3. Display the resulting table or plot.
4. Follow the output with a Markdown interpretation.
5. Relate the interpretation directly to the assignment question without making unsupported causal or population claims.

Before submitting a notebook, the group should confirm that:

- all required datasets load from the local `data` folder;
- all cells execute successfully in order;
- tables and plots have informative titles and labels;
- every requested output is followed by an interpretation;
- sample standard deviations use $n-1$ when required;
- potential outliers are investigated rather than automatically deleted;
- calculations and written conclusions agree with the displayed results;
- AI use is disclosed honestly; and
- every group member understands and can explain the submitted work.

## Group collaboration

- Pull the latest version before beginning work.
- Avoid editing the same notebook simultaneously, because notebook merge conflicts can be difficult to resolve.
- Use clear commit messages describing the completed change.
- Review one another's calculations and interpretations before submission.
- Keep original datasets unchanged and perform data processing inside the notebooks.
- Do not include personal information beyond what is required for the assignment.

## Use of AI

AI tools may be used to help structure notebooks, explain concepts, draft or debug code, check calculations, and improve written clarity when permitted by the assignment. AI-generated material must be reviewed critically and should not be accepted automatically. The group remains responsible for verifying the results, documenting its use of AI, and understanding everything included in the final submission.
